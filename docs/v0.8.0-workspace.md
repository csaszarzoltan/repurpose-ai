# v0.8.0 Content Workspace

The root URL now serves a responsive content-project workspace. It is intentionally focused on the repeated first step: save a source, select everyday outputs, and resume it later.

## Data location

Set `REPURPOSEAI_DATA_DIR`. The default is `./data`. The application creates `repurposeai.sqlite3` and enables SQLite WAL mode.

## Environment behavior

- `development` and `test`: unauthenticated calls use a local workspace, suitable for evaluation.
- `production`: project and telemetry endpoints require JWT authentication and use the authenticated user ID as the owner.

## API

- `POST /api/v1/projects`
- `GET /api/v1/projects?q=...&include_archived=false`
- `GET /api/v1/projects/{id}`
- `PATCH /api/v1/projects/{id}`
- `DELETE /api/v1/projects/{id}` archives the project
- `POST /api/v1/telemetry/events`

Telemetry event names and properties are allowlisted. Content, titles, prompts, passwords, tokens, secrets, and API keys are rejected.
