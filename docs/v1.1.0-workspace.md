# v1.1.0 Content Workspace

The root URL now serves a responsive content-project workspace. It is intentionally focused on the repeated first step: save a source, select everyday outputs, and resume it later.

## Data location

Set `REPURPOSEAI_DATA_DIR`. The default is `./data`. The application creates `repurposeai.sqlite3` and enables SQLite WAL mode.

## Environment behavior

- `development` and `test`: unauthenticated calls use a local workspace, suitable for evaluation.
- `production`: project and telemetry endpoints require JWT authentication and use the authenticated user ID as the owner.

## API

- `POST /api/v1/projects`
- `GET /api/v1/projects?q=...&include_archived=false`
- `GET /api/v1/projects/{id}`
- `PATCH /api/v1/projects/{id}`
- `DELETE /api/v1/projects/{id}` archives the project
- `POST /api/v1/telemetry/events`

Telemetry event names and properties are allowlisted. Content, titles, prompts, passwords, tokens, secrets, and API keys are rejected.


## Generated variants and safe review

- `POST /api/v1/projects/{id}/generate` creates a new version for every selected format.
- `GET /api/v1/projects/{id}/variants` returns only the latest version per format.
- Add `include_history=true` to receive complete version history.
- `PATCH /api/v1/projects/{id}/variants/{variant_id}` creates a new version instead of overwriting prior work.
- The current workspace explicitly labels output as `template_fallback` when no LLM router is configured. This output must be reviewed and cannot be mistaken for configured LLM generation.


## LLM provider behavior

The workspace automatically enables real LLM generation when one or more of these variables is set:

```bash
export OPENROUTER_API_KEY=...
export OPENAI_API_KEY=...
export ANTHROPIC_API_KEY=...
```

Only providers with a non-empty key are registered. Fallback order remains OpenRouter, OpenAI, then Anthropic. All 20 format templates are registered for workspace generation.

Generation responses expose one of three modes:

- `llm`: a configured provider generated the result without warnings.
- `template_fallback`: no provider was configured, so the deterministic fallback was used.
- `llm_fallback`: at least one provider was configured but generation produced a warning and the service returned fallback content.

The latter two modes are deliberately visible so users know that review is required.


## Saved recipes

Recipes persist the settings users repeat most often: target formats, brand voice, and custom instructions. They do not copy source content, titles, publication state, or generated drafts.

API endpoints:

- `POST /api/v1/recipes`
- `GET /api/v1/recipes`
- `PATCH /api/v1/recipes/{recipe_id}`
- `DELETE /api/v1/recipes/{recipe_id}`
- `POST /api/v1/recipes/{recipe_id}/projects`

Recipes are owner-scoped through the same production JWT and local-development workspace policy as projects. Updating a recipe does not retroactively alter existing projects.
